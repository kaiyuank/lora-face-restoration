# Code guide

Research code accompanying the [project report](../report.pdf).

| Folder | Contents |
| --- | --- |
| `guided_diffusion/` | Diffusion models, LoRA layers, and training utilities |
| `scripts/` | Full fine-tuning and LoRA training/restoration experiments |
| `tools/` | Face alignment and forward-diffusion visualization |

The code includes attention, residual-convolution, and timestep-embedding LoRA variants.

Selected research code is provided here; datasets, model checkpoints, and full experimental outputs are maintained separately on the research server.

Based on [Gen2Res](https://github.com/adobe-research/gen2res). See the [Adobe Research License](LICENSE) for the inherited code and its modifications.
